# 📼 カセットプレーヤー

**ローカルの音楽フォルダを読み込んで再生する、レトロなカセットテープ風ミュージックプレーヤーです。**
青を基調としたシンプルなデザインで、ブラウザだけで動きます(インストール・ビルド不要)。

## ✨ 機能

- 📁 **ローカルフォルダ読み込み** — PCやスマホの音楽フォルダを選ぶだけ(MP3 / M4A / AAC / OGG / WAV / FLAC 対応)
- 📼 **カセットデッキ風の再生画面** — SVGで描いたリアルなカセットテープを、ガラス窓付きのデッキに装着した見た目。再生中はリールが回転し(テープの巻き半径に反比例した回転速度)、再生位置に合わせてテープの巻き量が変化します
- 📊 **VUメーター & テープカウンター** — VUメーターは Web Audio API の AnalyserNode で実際の音声レベルに反応。カウンターも再生位置に連動
- 🎛️ **メカニカルなボタン** — REW / PLAY / FF の押しボタン式。再生中は PLAY キーが押し込まれたままになります
- 💿 **アルバムジャケット一覧** — MP3のタグからジャケット画像を読み取ってグリッド表示
- ❤️ **お気に入り** — ワンタップで登録。ブラウザに保存されるので次回も残ります
- 🎶 **プレイリスト** — 作成・追加・削除。こちらも自動保存
- 🏷️ **ジャンル分け** — タグのジャンル情報で自動分類
- 🔀 **シャッフル再生**
- 📸 **スクショ機能** — 再生中画面をSNS投稿用の画像(1080×1080 PNG)として生成し、共有 or ダウンロード

## 🚀 使い方

### 📱 Android で使う(かんたん)

1. このブランチを push すると GitHub Actions が自動で GitHub Pages に公開します
   (初回のみ: リポジトリの **Settings → Pages → Source** を「**GitHub Actions**」にしてください)
2. Android の Chrome で `https://<ユーザー名>.github.io/test01/music-player/` を開く
3. 「🎵 曲ファイルを選ぶ」から端末内の音楽ファイルを選択(Androidはフォルダ選択非対応のため)
4. メニュー(⋮)→「**ホーム画面に追加**」で、アプリとしてインストールできます(PWA対応・オフライン起動可)

### 💻 PC でローカルに試す

```bash
# リポジトリのルートで簡易サーバーを立てる(Python が入っていれば)
python -m http.server 8000
# → ブラウザで http://localhost:8000/music-player/ を開く
```

1. 「📁 フォルダを開く」で音楽の入ったフォルダを選ぶ
2. アルバム / 曲 / ジャンル から曲をタップして再生
3. 画面下のミニプレーヤーをタップするとカセット画面が開きます
4. カセット画面右上の 📸 でスクショをSNSにシェア

> 曲名・アーティスト・アルバム・ジャンル・ジャケットは MP3 の ID3v2 タグから読み取ります。
> タグがないファイルはファイル名で表示されます。
> ファイル自体はブラウザの外に送信されません(すべてローカルで処理されます)。

## 🛠️ 技術構成

- Vanilla JS(ES Modules)のみ。外部ライブラリ・ビルド不要
- File System Access API(非対応ブラウザでは `webkitdirectory` にフォールバック)
- 自前の最小 ID3v2 パーサー(`js/id3.js`)でタグ・ジャケット画像を抽出
- Canvas でシェア画像を描画し、Web Share API で共有(非対応環境ではPNGダウンロード)
- お気に入り・プレイリストは `localStorage` に保存

## 📁 ファイル構成

```
index.html   # 画面の骨組み
style.css    # 青基調のスタイル + カセットのCSSアート
js/
├─ main.js   # 状態管理・画面描画・再生制御
├─ id3.js    # ID3v2タグの最小パーサー
└─ share.js  # SNSシェア用スクショ画像のCanvas描画
```
