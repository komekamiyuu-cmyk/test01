# 📼 カセットプレーヤー

**ローカルの音楽フォルダを読み込んで再生する、レトロなカセットテープ風ミュージックプレーヤーです。**
ブラウザだけで動きます(インストール・ビルド不要)。

## 🎨 デザイン

80年代のVHS / カセットのパッケージデザインを下敷きにした、グラフィック寄りの見た目です。

- **配色** — クリーム地(`#E8E2D5`)+ 温かみのあるグレー + オレンジ赤のアクセント(`#EE3B12`)。
  黄 → 橙 → 赤 → 赤紫のストライプ帯をヘッダーとVUメーターで共通の意匠に
- **書体** — 見出しに Archivo Black(重量級グロテスク)、ラベル・数値に Oswald(圧縮体)。
  CDNに依存せず `fonts.css` に埋め込んでいるのでオフラインでも同じ見た目になります
- **再生中画面** — 実物のカセットテープの縮尺と構造をそのまま描いています。
  成形プラスチックの陰影、窓のアクリルの映り込み、巻かれたテープの層、金属ハブ、
  沈んだネジ、下端のヘッド開口部とパッドまで。上半分は貼られた紙ラベルで、
  そこに曲名・アーティスト・ジャケット・シリアル番号が載ります

## ✨ 機能

- 📁 **ローカルフォルダ読み込み** — PCやスマホの音楽フォルダを選ぶだけ(MP3 / M4A / AAC / OGG / WAV / FLAC 対応)
- 📼 **カセットの再生画面** — 窓の奥に巻かれたテープとリールが見えます。再生中はリールが回転し(テープの巻き半径に反比例した回転速度)、再生位置に合わせて左右の巻き量が入れ替わります
- 📊 **VUメーター & テープカウンター** — VUメーターは Web Audio API の AnalyserNode で実際の音声レベルに反応。カウンターも再生位置に連動
- 🎛️ **メカニカルなボタン** — REW / PLAY / FF の押しボタン式。再生中は PLAY キーが押し込まれたままになります
- 💿 **アルバムジャケット** — MP3 / M4A / FLAC / OGG のタグからジャケットを読み取り、一覧と再生中画面の両方に表示
- ❤️ **お気に入り** — ワンタップで登録。ブラウザに保存されるので次回も残ります
- 🎶 **プレイリスト** — 作成・追加・削除。こちらも自動保存
- 🏷️ **ジャンル分け** — タグのジャンル情報で自動分類
- 🔀 **シャッフル再生**
- 📸 **スクショ機能** — 再生中画面をSNS投稿用の画像(1080×1080 PNG)として生成し、共有 or ダウンロード

## 📱 Androidアプリ(APK)として使う

**これが一番おすすめの使い方です。** ブラウザを開かず、端末にインストールしたアプリとして起動できます。

Web版との一番の違いは **曲を選ぶ操作が要らない** ことです。Android版は OS が持っている音楽の
インデックス(MediaStore)を直接読むので、起動した瞬間に一覧が出ます。
題名・アーティスト・アルバム・ジャンル・ジャケットも OS 側の情報をそのまま使います。

### 読み込むフォルダ

端末内の **`TapePlayer`** という名前のフォルダを優先して読み込みます(例: `Music/TapePlayer`)。
そこに曲を置いておけば、起動しただけでそのフォルダの中身が一覧に並びます。
`TapePlayer` フォルダが無い、または空の場合は、端末内の全曲を読み込みます。

読み込むフォルダ名を変えたい場合は `MediaLibrary.kt` の `PREFERRED_FOLDER` を書き換えてください。

### APK の入手

1. リポジトリの **Actions** タブ → **Build Android APK** の最新の実行を開く
2. 下部の **Artifacts** から `cassette-player-apk` をダウンロードして展開
3. 出てきた `app-debug.apk` をスマホに移してタップ
4. 「提供元不明のアプリ」の確認が出たら許可する(自分でビルドしたアプリなので通常の手順です)
5. 初回起動時に「音楽とオーディオへのアクセス」を許可する

> 画面(HTML/CSS/JS)は `music-player/` をビルド時に APK へ同梱しているため、
> Web版と Android版でデザインの実装が二重になることはありません。
> インターネット権限は要求しないので、曲も画面も全て端末内で完結します。

### 自分でビルドする場合

```bash
cd android
./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

## 🚀 ブラウザで使う

### 📱 Android で使う(かんたん)

1. このブランチを push すると GitHub Actions が自動で GitHub Pages に公開します
   (初回のみ: リポジトリの **Settings → Pages → Source** を「**GitHub Actions**」にしてください)
2. Android の Chrome で `https://<ユーザー名>.github.io/test01/music-player/` を開く
3. 「🎵 曲ファイルを選ぶ」から端末内の音楽ファイルを選択(Androidはフォルダ選択非対応のため)
4. メニュー(⋮)→「**ホーム画面に追加**」で、アプリとしてインストールできます(PWA対応・オフライン起動可)

### 💻 PC でローカルに試す

```bash
# リポジトリのルートで簡易サーバーを立てる(Python が入っていれば)
python -m http.server 8000
# → ブラウザで http://localhost:8000/music-player/ を開く
```

1. 「📁 フォルダを開く」で音楽の入ったフォルダを選ぶ
2. アルバム / 曲 / ジャンル から曲をタップして再生
3. 画面下のミニプレーヤーをタップするとカセット画面が開きます
4. カセット画面右上の 📸 でスクショをSNSにシェア

> 曲名・アーティスト・アルバム・ジャンル・ジャケットは MP3 / M4A / FLAC / OGG のタグから読み取ります。
> タグが無い場合はファイル名と、フォルダから読み込んだときは親フォルダ名をアルバム名に使います。
> ファイル自体はブラウザの外に送信されません(すべてローカルで処理されます)。

## 🛠️ 技術構成

- Vanilla JS(ES Modules)のみ。外部ライブラリ・ビルド不要、ネットワーク接続も不要
- File System Access API(非対応ブラウザでは `webkitdirectory` にフォールバック)
- 自前のタグ解析(`js/metadata.js`)。MP3(ID3v2 / ID3v1)・M4A(MP4ボックス)・FLAC・OGG に対応
- Canvas でシェア画像を描画し、Web Share API で共有(非対応環境ではPNGダウンロード)
- お気に入り・プレイリストは `localStorage` に保存

## 🔧 改造する

見た目もふるまいも、普通のHTML/CSS/JSを書き換えるだけで変えられます。
**Android版も同じファイルを読んでいる**ので、直せば両方に反映されます。

| やりたいこと | 触るファイル |
|---|---|
| 色を変える・書体を変える | `theme.css` だけ。ここの値が画面全体とシェア画像に効きます |
| 余白・大きさ・配置を変える | `style.css` |
| カセットの絵を変える | `index.html` のSVG(再生画面)と `js/share.js`(シェア画像)。同じ400×252の座標系なので、片方の数値をもう片方にそのまま移せます |
| 一覧の並び・タブを変える | `js/main.js` の `render()` |
| Androidの再生まわりを変える | `android/app/src/main/java/.../PlayerBridge.kt` |

変更後の確認:

```bash
python -m http.server 8000     # ブラウザ版はこれだけで反映
cd android && ./gradlew assembleDebug   # APKに反映
```

## 📁 ファイル構成

```
music-player/          # 画面(ブラウザ版とAndroid版で共用)
├─ index.html          # 骨組み + カセットのSVG
├─ theme.css           # ★ 色と書体の定義(見た目を変えるならまずここ)
├─ style.css           # レイアウトと部品のスタイル
├─ fonts.css           # Archivo Black / Oswald を data URI で埋め込み
├─ js/
│  ├─ main.js          # 状態管理・画面描画・再生制御
│  ├─ folderstore.js   # 選んだフォルダを覚えて次回起動時に開き直す
│  ├─ metadata.js      # MP3/M4A/FLAC/OGG のタグ読み取り(ブラウザ版で使用)
│  ├─ demo.js          # デモ曲(音もジャケットもその場で合成)
│  └─ share.js         # SNSシェア用スクショ画像のCanvas描画
└─ manifest.json / sw.js / icons/   # PWA(ホーム画面に追加・オフライン起動)

android/               # Androidアプリ(APK)
└─ app/src/main/java/io/github/komekamiyuu/cassette/
   ├─ MainActivity.kt     # WebViewの土台・端末内リクエストの解決・共有
   ├─ MediaLibrary.kt     # MediaStoreから曲一覧を読む
   ├─ PlaybackService.kt  # バックグラウンド再生とロック画面の操作パネル
   └─ PlayerBridge.kt     # 画面から再生を操作する窓口
```
