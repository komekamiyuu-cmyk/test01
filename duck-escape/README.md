# 🦆 アヒル逃走記 3D

**2体の鬼と、ペットのアヒルの追いかけっこ。どちらがわでも遊べる3Dアクションです。**

- 🦆 **アヒルであそぶ** … 2体の鬼から逃げながら、落ちている **銃** と **手裏剣** で戦う
- 👹 **鬼であそぶ** … 逃げるアヒルを **金棒** で追いかけてつかまえる

**そうさ「おまかせ」なら、うごかすだけ**(ねらう・こうげき・カメラは全部じどう)なので、
小さな子どもでも遊べます。ブラウザだけで動きます(インストール・ビルド・ライブラリ不要)。

![対応環境](https://img.shields.io/badge/Windows-Chrome%20%2F%20Edge-blue) ![対応環境](https://img.shields.io/badge/Android-Chrome-green) ![依存](https://img.shields.io/badge/依存ライブラリ-なし-orange)

## ▶ あそびかた

### いちばんかんたん: 1ファイル版(パソコン向け)

**[`standalone.html`](standalone.html)** をダウンロードして、**ダブルクリックするだけ**で遊べます。
(GitHub の `standalone.html` のページを開き、右上の **Download raw file** ボタンで保存してください)

ゲーム一式が1つのHTMLに入っているので、サーバーもインストールも不要です。

### 📱 Androidスマホであそぶ

**方法1: 公開URLを開く(おすすめ)**

GitHub Pages などに公開していれば、スマホのChromeでURLを開くだけです。
Chromeメニューの **「ホーム画面に追加」** を選ぶと、アプリのように全画面で起動でき、
オフラインでも遊べます(PWA対応)。

**方法2: 1ファイル版をスマホに保存して開く**

1. スマホのChromeで GitHub の `standalone.html` を開き、**Download raw file** で保存
2. **Files(ファイル)アプリ** や Chrome の「ダウンロード」から `standalone.html` をタップ
3. 「Chromeで開く」を選ぶ → そのまま遊べます

スマホでは次のことを自動でやります。

- **全画面表示**にして、できれば**横向きに固定**(スタートを押したとき)
- 遊んでいる間は**画面が消えない**ようにする(スリープ防止)
- 端末が重いときは**描画の解像度を自動で下げて**、動きのなめらかさを優先
- たて画面のときは「よこにしてね」と案内(たてのままでも遊べます)

操作は画面左下の**スティック**で移動、右下の**よけるボタン**でダッシュ。
そうさ「おまかせ」なら、**スティックだけ**で遊べます。

### もとの形(モジュール版)で動かす

`index.html` は ES Modules を使っているので、簡易サーバー経由で開いてください
(ファイルを直接ひらくとブラウザの制限で読み込めません。その場合は画面に案内が出ます)。

```bash
cd duck-escape
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```

GitHub Pages に公開している場合は `/duck-escape/` でそのまま遊べます。

> `standalone.html` は自動生成ファイルです。`js/` を変更したら
> `node build-standalone.mjs` で作り直してください。

## 🎮 操作

タイトル画面で **そうさ** をえらべます。

### そうさ「おまかせ」(おすすめ・子ども向け)

**うごかすだけ**です。いちばん近い相手に自動でねらいを付け、自動でこうげきし、
カメラも自動で相手の方をむきます。ダッシュ(回避・突進)も自動で出ます。弾切れもありません。

| | 動作 |
|---|---|
| パソコン: `W` `A` `S` `D` / 矢印キー | 移動 |
| スマホ: 左スティック | 移動 |
| `Shift` / 「ダッシュ」ボタン | ダッシュ(自分で出すこともできる) |
| `P` / `Esc` | ポーズ |

### そうさ「じぶんで」

| パソコン | 動作 |
|---|---|
| `W` `A` `S` `D` / 矢印キー | 移動(カメラの向きが「前」) |
| マウス移動 | 視点を回す(画面クリックでマウスをロック) |
| 左クリック / `Space` | 攻撃(押しっぱなしで連射) |
| `Shift` | ダッシュ(短いあいだ無敵。攻撃をよける) |
| `Q` / `1` `2` `3` | 武器チェンジ(アヒル側のみ) |

スマホは「画面右側をなぞる」で視点、「うつ」ボタンで攻撃です。

## 🎯 ルール

### 🦆 アヒルであそぶ(にげる側)

1. ラウンドごとに **赤鬼** と **青鬼** が出現します。2体ともたおすと次のラウンドへ。
2. ラウンド3の鬼をたおすと **鳥居のゲート** がひらきます。そこまで走れば **クリア!**
3. 体力(❤️×5)がゼロになるとゲームオーバー。ハートを拾うと1回復します。
4. 頭の上の矢印が、いちばん近い鬼(脱出時はゲート)の方向を指します。

### 👹 鬼であそぶ(おいかける側)

1. にげるアヒルを **金棒** でなぐって、ハート5つを0にすれば **つかまえた!**
2. ラウンドは3回。1ラウンドは **75秒** の制限時間つき。時間切れは「にげられた…」。
3. アヒルは落ちている武器をひろって **うちかえしてきます**。鬼の体力も❤️×5。
4. ラウンド1から **青鬼のなかま** が手伝ってくれます。落ちているハートは鬼も拾えます。

### 武器

| 武器 | 特徴 |
|---|---|
| ✴️ 手裏剣 | 3枚が扇状に飛び、敵を貫通する。最初から5枚持っている |
| 🔫 ピストル | まっすぐ速く飛ぶ。1発の威力が高い |
| 💥 マシンガン | ラウンド2以降にまれに出現。連射がとにかく速い |

同じ武器を拾うと弾が増え、拾った武器にすぐ持ち替わります。

### 鬼

| 鬼 | 戦い方 |
|---|---|
| 赤鬼 | まっすぐ追ってきて **金棒** でなぐる。振りかぶり(大きなモーション)が攻撃の合図 |
| 青鬼 | 距離をとりながら **鬼火** を投げる。ラウンド3では3発同時に飛んでくる |

どちらも「振りかぶってから当たる」ので、モーションを見てから **ダッシュ** でよけられます。

## 🏗️ つくり(設計)

外部ライブラリは使っていません。3D描画は**素のWebGLで書いた小さなレンダラ**です。

```
index.html                画面の骨組み(canvas + HUD + タイトル/結果画面)
standalone.html           1ファイル版(自動生成。ダブルクリックで遊べる)
build-standalone.mjs      1ファイル版を作るスクリプト(node build-standalone.mjs)
icons/                    ホーム画面に追加したときのアイコン(icon.svg から生成)
style.css                 HUDとメニューのスタイル
manifest.json / sw.js     PWA(ホーム画面に追加/オフライン対応)
js/
├─ main.js                エントリポイント。配線・ラウンド進行・カメラ・スコア
├─ config.js              ★ゲームバランス(ここだけ触れば強さや難易度を調整できる)
├─ hud.js                 HUDと画面遷移(DOMの書き換えだけを担当)
├─ engine/                汎用の3Dエンジン(ゲームの内容を知らない層)
│   ├─ math.js            ベクトルと4x4行列
│   ├─ geometry.js        箱・球・円柱・円錐・星などの形づくりと合成
│   ├─ gl.js              シェーダと描画(平行光源+リムライト+フォグ)
│   └─ scene.js           親子関係を持つノードとカメラ
├─ models/                見た目(ノードを組み合わせたモデル)
│   ├─ meshes.js          共有メッシュ(基本形をGPUに1度だけ送る)
│   ├─ parts.js           被弾の点滅・頭上のHPバー
│   ├─ duck.js            アヒル
│   ├─ oni.js             鬼(赤=金棒 / 青=鬼火)
│   ├─ items.js           銃・マシンガン・手裏剣・ハート
│   └─ world.js           ステージ(地面・塀・岩・木・灯籠・鳥居)
└─ game/                  ゲームの中身
    ├─ input.js           キーボード / マウス / タッチ
    ├─ audio.js           効果音とBGM(Web Audioで合成。音声ファイル不要)
    ├─ player.js          アヒル(あなた)の移動・ダッシュ・射撃・被弾
    ├─ enemy.js           鬼のAI(追跡・振りかぶり・攻撃)
    ├─ oni-player.js      鬼(あなた)の移動・ダッシュ・金棒     ← 鬼モード
    ├─ duck-ai.js         逃げるアヒルのAI(逃走・アイテム回収・反撃) ← 鬼モード
    ├─ projectiles.js     弾/手裏剣/鬼火の飛翔と当たり判定
    ├─ pickups.js         落ちているアイテム
    └─ effects.js         粒と波紋(プール方式)
```

### データの流れ

```
入力(input) ─→ main.js の step()
                 ├→ player.update()   移動・向き
                 ├→ player.fire()     → projectiles.spawn()
                 ├→ enemy.update()    追跡・攻撃 → projectiles / player.takeDamage()
                 ├→ projectiles.update() 当たり判定 → onHitOni / onHitPlayer
                 └→ pickups.update()  取得 → player.give()
                            ↓
             scene(ノードの木)→ collect() で描画リスト → gl.js が1回で描く
```

**重要な決めごと**

- `engine/` はゲームの内容を知りません(アヒルも鬼も知らない)。3Dの都合はここに閉じ込めています。
- 「あなた」と「相手」は共通のかたち(`x` / `z` / `radius` / `takeDamage()` …)を持つので、
  弾やアイテムのコードは、どちらのモードでもそのまま使えます。
- 当たり判定はすべて「上から見た円どうし」。軽くて、スマホでも動きます。
- 形は `geometry.js` の基本形だけで作ります。テクスチャ画像は1枚も使いません。

### よくある変更をどこでやるか

| やりたいこと | 触る場所 |
|---|---|
| 鬼を強く/弱くする | `config.js` の `ONI` と `roundScale()` |
| 「おまかせ操作」の中身 | `config.js` の `CONTROLS` |
| 鬼モードのバランス | `config.js` の `ONI_PLAYER` / `DUCK_AI` / `ONI_MODE` |
| 武器の威力・弾数・連射速度 | `config.js` の `WEAPONS` |
| ラウンド数、難易度の倍率 | `config.js` の `ROUNDS` / `DIFFICULTY` |
| アイテムの出やすさ | `config.js` の `PICKUPS` |
| ステージの広さ・地形 | `config.js` の `ARENA`、`models/world.js` |
| 新しい武器を追加 | `config.js` に定義を足す → `models/items.js` に見た目を足す |
| キャラの見た目 | `models/duck.js` / `models/oni.js` |
