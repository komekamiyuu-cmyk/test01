# ✍️ てがきメモ(PWA版プロトタイプ)

**Androidタブレット向けの手書きメモアプリ。** スタイラスで書いて、フォルダで整理できます。
ブラウザだけで動くので、インストールもビルドも不要です。

## すぐ試す

```bash
# リポジトリのルートで
python -m http.server 8000
# → タブレットの Chrome で http://<PCのIP>:8000/handwriting-memo/ を開く
```

Chrome のメニューから **「ホーム画面に追加」** すると、アドレスバーのない全画面アプリとして起動します(PWA)。
オフラインでも動きます。

## できること

### 書く
| 機能 | 説明 |
|---|---|
| **ペン** | 筆圧に反応して線の太さが変わります(S Pen などのスタイラス)。太さ4段階・色7色 |
| **マーカー** | 半透明の蛍光ペン。文字の上に重ねても読めます |
| **消しゴム** | なぞった線を1本ずつ消します。**ペンのお尻ボタン**を押すと自動で消しゴムに切り替わります |
| **なげなわ選択** | 囲んで選んで、ドラッグで移動・複製・削除 |
| **元に戻す / やり直す** | 200手前まで。Ctrl+Z / Ctrl+Shift+Z にも対応 |
| **手のひら誤爆防止** | ペンを検出している間はタッチを無視します(パームリジェクション) |
| **2本指操作** | 2本指でスクロール、ピンチでズーム(20%〜500%) |
| **用紙** | 無地 / 横罫 / 方眼 / ドット。ページは何枚でも追加できます |

### 整理する
- **フォルダ**(入れ子OK)にメモを分類。サブフォルダも作れます
- メモの **移動 / 複製 / 名前変更 / 削除**、フォルダへのドラッグ&ドロップ(マウス操作時)
- **検索**(メモ名)、**並び替え**(更新順 / 作成順 / 名前順)
- 一覧には **手書きのサムネイル** が並びます

### 記録を残す
- 書いた内容は **自動保存**(IndexedDB)。アプリを閉じても消えません
- **JSONバックアップ / 復元**(サイドバー下部)。機種変更時のデータ移行に使えます
- **PNG書き出し**(表示中のページを画像として保存)

## 操作のこつ

- 指で描きたいときは、左のツールバー一番下の **👆** をオンにします(オフのときは指＝スクロール専用)
- **⤢** で用紙の幅に合わせて表示を戻せます
- 画面が狭いときは左上の **☰** でフォルダ一覧を開きます

## 構成

```
handwriting-memo/
├── index.html
├── css/style.css
├── js/
│   ├── main.js      画面の切り替えとツールバーの配線
│   ├── library.js   一覧画面(フォルダツリー / メモカード)
│   ├── editor.js    手書きキャンバス(入力・ジェスチャ・履歴)
│   ├── ink.js       描画エンジン(ストローク / 用紙 / 書き出し)
│   ├── model.js     データ構造と幾何計算
│   ├── store.js     状態管理と保存
│   ├── db.js        IndexedDB ラッパー
│   └── ui.js        ダイアログ・トースト
├── sw.js            オフライン用 Service Worker
└── manifest.json
```

データは端末内の IndexedDB(`tegaki-memo`)にだけ保存され、外部には一切送信しません。

- **notes** … メモのメタ情報(名前・フォルダ・更新日時・サムネイル)
- **docs** … 手書きの本体。ストロークを `[x, y, 筆圧, ...]` のベクタで持つため、拡大しても線がぼけません
- **folders** … フォルダ(親子関係つき)

## 制限(プロトタイプのため)

- 手書き文字の検索・テキスト化(OCR)は未対応(検索はメモ名のみ)
- PDF書き出し、画像の貼り付け、図形認識は未実装
- 端末間の同期はなし(JSONバックアップで手動移行)
