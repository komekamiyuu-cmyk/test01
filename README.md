# 🎵 かんたんDAW

**タップするだけで曲がつくれる、初心者向けの音楽制作アプリ(DAW)です。**
Windows でも Android でも、ブラウザひとつで動きます。インストールも面倒な設定も不要です。

![対応環境](https://img.shields.io/badge/Windows-Edge%20%2F%20Chrome-blue) ![対応環境](https://img.shields.io/badge/Android-Chrome-green)

## ✨ 特徴 — 「むずかしい」をなくしました

| よくあるDAWのハードル | かんたんDAWの答え |
|---|---|
| 音楽理論がわからない | **スケール固定**なので、どのマスを押してもキレイに響きます(音を外せません) |
| 画面がゴチャゴチャして難しい | トラックは **ドラム / コード / ベース / メロディの4つだけ**。タブで切り替えるシンプル画面 |
| 何から始めればいいかわからない | **デモ曲ボタン**でお手本を再生。使い方ガイドも初回に自動表示 |
| 機材や音源が必要 | 音はぜんぶブラウザ内で合成。**マウスか指だけ**で作れます |
| 保存やファイル管理が面倒 | **自動保存**。閉じても続きから作れます |

### できること

- 🥁 **ドラム打ち込み** — キック・スネア・ハイハット・手拍子をステップ入力
- ❄️ **アイスパッド** — 氷系ドラムマシン。ICE / VAPORWAVE(808) / テクスチャの3キット × 4バンク、リバーブ・ピッチ調整つき
- 🎹 **コード** — ポップスの定番コード4つをワンタップで配置
- 🎸 **ベース / メロディ** — なぞるだけで入力。音色も選べる
- ✨ **アイスシンセ** — きらめくFMポリシンセ。クリスタル / グレイシャー / シャターなど6プリセット
- ⏱️ テンポ変更(60〜180 BPM)、キー・スケール変更(ペンタトニック / メジャー / マイナー)
- 💾 **WAVファイル書き出し**(作った曲を音声ファイルとして保存)
- 📤 曲データの書き出し / 読み込み(JSON)
- 📱 **PWA対応** — ホーム画面に追加すればアプリとして起動、オフラインでも動作

## 🚀 使い方

### すぐに試す(ローカルで開く)

このリポジトリをダウンロードして、フォルダ内で簡易サーバーを立てます:

```bash
# Python が入っていれば
python -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

> `index.html` を直接ダブルクリックしても動きますが、PWA機能(インストール・オフライン)はサーバー経由でのみ有効です。

### Webに公開する(GitHub Pages・無料)

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「GitHub Actions」にする
3. `main` ブランチにこのコードをマージすると、自動でデプロイされます(`.github/workflows/pages.yml` 同梱)
4. 発行されたURLを Windows / Android のブラウザで開くだけ

### アプリとしてインストール

- **Windows (Edge / Chrome)**: アドレスバー右端の「インストール」アイコン(⊕)をクリック
- **Android (Chrome)**: メニュー(⋮)→「ホーム画面に追加」または「アプリをインストール」

インストール後は普通のアプリと同じように起動でき、オフラインでも使えます。

## 🎼 曲づくりの流れ(3ステップ)

1. **ドラム**タブでマスをタップしてリズムを作る
2. **▶ 再生**を押してループを聴きながら調整
3. **コード → ベース → メロディ**の順に音を重ねる

迷ったら **🎧 デモ曲** ボタンでお手本を読み込めます。

## 🛠️ 技術構成

- **Vanilla JS(ES Modules)+ Web Audio API** — 外部ライブラリ・ビルド不要の静的サイト
- 全楽器音をリアルタイム合成(サンプル音源ファイルなし → 軽量・高速起動)
- 先読みスケジューラー方式で正確なタイミング再生
- `OfflineAudioContext` によるWAV書き出し
- Service Worker + Web App Manifest による PWA(オフライン対応・インストール可能)
- **楽器はプラグイン方式** — `js/instruments/` に1ファイル追加するだけで新しいトラックが増える設計。詳しくは [ARCHITECTURE.md](ARCHITECTURE.md)

## 📁 ファイル構成

```
index.html        # 画面の骨組み
style.css         # スタイル(スマホ/PC両対応)
js/
├─ main.js        # エントリポイント(モジュールの配線)
├─ config.js      # スケール・コードなど音楽の共通定義
├─ state.js       # 曲データの保存/読込
├─ audio/         # バス・スケジューラ・WAVエンコード
├─ ui/            # グリッド描画・設定UI部品
└─ instruments/   # 楽器(1ファイル=1トラック)
manifest.json     # PWAマニフェスト
sw.js             # Service Worker(オフラインキャッシュ)
icons/            # アプリアイコン
ARCHITECTURE.md   # 設計ドキュメント(メンテナンス・拡張ガイド)
```
